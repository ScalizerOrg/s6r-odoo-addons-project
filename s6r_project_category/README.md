Scalizer Project Category
========================

This module adds a category on projects.It allows users to assign a category to each
project in order to better organize and analyze projects.

## Usage

1. Go to **Project > Configuration > Project Categories**
2. Create the categories you want to use
3. Open a project and set its **Category**
4. Use the search view to filter or group projects by category.
